# 🎂 Happy Birthday Salma Salsabila Rahma (25th Birthday) ✨

Website interaktif spesial perayaan ulang tahun ke-25 untuk Salma Salsabila Rahma.

## ✨ Fitur-Fitur Utama
- 💌 **Amplop Pembuka 3D**: Animasi interaktif dengan pemutaran lagu otomatis.
- 🎂 **Kue Ulang Tahun 3D Interaktif**: Dilengkapi efek tiup lilin, taburan hati, dan konfeti kembang api.
- 🌟 **Kartu Harapan "Rayakan!"**: Menampilkan modal pop-up doa & harapan terbaik untuk usia ke-25.
- 📸 **Galeri Foto Kenangan (Marquee Collage 3-Track)**: Slider otomatis yang menampilkan 176 momen kenangan manis beserta viewer lightbox HD.
- 🔐 **Surat Cinta Rahasia (Love Letter)**: Dilindungi password khusus dengan animasi amplop terbuka.
- ✍️ **Kirim Doa & Pesan**: Form interaktif untuk menulis ucapan dan memilih emoji yang langsung tersimpan.

## 🚀 Menjalankan Secara Lokal
```bash
npm install
npm start
```
Buka browser di `http://localhost:3000`.

## 🌐 Deploy
Website ini menggunakan Node.js Express dan siap di-deploy langsung ke **Render.com**, **Railway.app**, atau hosting Node.js lainnya.
